# Dashboard de Ventas

## Descripción

Dashboard administrativo desarrollado para la gestión y visualización de información relacionada con ventas.

El proyecto presenta un diseño moderno y responsive que permite visualizar estadísticas, ventas mensuales y ventas recientes.

## Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design
- Media Queries
- Variables CSS
- Accesibilidad web
- GitHub

## Características

- Barra lateral de navegación.
- Encabezado administrativo.
- Tarjetas de resumen.
- Gráfico de ventas mensuales.
- Tabla de ventas recientes.
- Efectos hover.
- Transiciones CSS.
- Diseño responsive.
- Adaptación para computador, tablet y celular.
- Uso de roles ARIA.
- Navegación mediante teclado.

## Diseño responsive

El dashboard fue diseñado para adaptarse a diferentes tamaños de pantalla:

### Escritorio

Las tarjetas se muestran en cuatro columnas.

### Tablet

Las tarjetas se organizan en dos columnas.

### Celular

Las tarjetas se organizan en una sola columna y la barra lateral se oculta.

## Accesibilidad

Se utilizaron etiquetas HTML5 semánticas, atributos ARIA, estados `:focus` y contraste adecuado para facilitar la navegación y accesibilidad.
